# 🌾 Crop Nexus
### Smart Crop-Loss Reporting & Farmer Support Platform

Crop Nexus is a digital agriculture platform designed to help farmers report crop damage, track compensation claims, access crop recovery guidance, and receive weather alerts through a single interface.

The platform also provides dedicated dashboards for government officers to support inspection and digital e-Panchanama documentation workflows.

## 🎯 Problem Statement

Farmers affected by crop damage may face difficulties with reporting losses, completing documentation, tracking compensation claims, and accessing timely agricultural information.

Crop Nexus aims to bring these services together in one accessible digital platform.

## 💡 Our Solution

Crop Nexus provides an integrated platform connecting farmers, field officers, and administrators to make crop-loss reporting and related support processes more organized and accessible.

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rohitchaudhari045-eng/Crop-Nexus.git
   ```

2. Open the project folder:

   ```bash
   cd Crop-Nexus
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
